TDX → cSurvey mapping workbench

How to use: open cs-targets.html in a second window for the numbered menu. In each row's box type a target number (points take 1–99, lines 101–113, areas 201–206), or label:TEXT (points only), or leave. Empty = default behavior. The → preview updates live. Then press the button — it downloads tdx-mapping.json; replace dev/tools/tdx-mapping.json with it and re-run preprocess_tdx_csx.py. Prefilled boxes show the current explicit mapping.
