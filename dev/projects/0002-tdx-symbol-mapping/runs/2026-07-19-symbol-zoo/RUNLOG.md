## step-03 — zoo v3 (2026-07-19, agent) — per user request (v2 superseded pre-import)

v2 (one long 170 m traverse) was superseded before import on user feedback:
labels collided and the stretch was unsnippable. `make_symbol_zoo.py` v3:

- **grid layout, 20 symbol slots per row**, rows 12 m apart — snippable row by row;
- **labels alternate below/above** the centerline (even/odd column) — no collisions;
- **station names ARE the symbol tags** (`P07`, `L12`, `A03`, `C00`…) — the
  centerline stations label the slots directly; shot distance/bearing computed
  from grid coordinates so the solved network reproduces the layout exactly;
- text label ("P07 crystal") at every item; `section` point slot label-only;
- calibrations on their own final row: CAL1 single CW wall, CAL2 passage
  (anti-parallel strokes = consistent winding), CAL3 passage (parallel =
  inconsistent).
